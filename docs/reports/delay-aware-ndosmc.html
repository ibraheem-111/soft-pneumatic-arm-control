Delay-Aware SMC

Paper SMC (Qiao, Tao & Zhang 2024, eq. 5) on model M2, plus a Smith predictor for the dead time and a lag inverse. The paper's disturbance observer is optional (measured effect ≤ 0.03 mm). Code: DelayAwareNDOSMC in scripts/ndosmc.py (observer=False for the base controller); notebook §14.

Notation

\[ \begin{aligned} u &= (u_2, u_3, u_4)^{\mathsf T},\ u_j = P^{\text{cmd}}_{Sj} - 4.5 && \text{input (psi)}\\ p &= (p_2, p_3, p_4)^{\mathsf T},\ p_j = P^{\text{meas}}_{Sj} - P^{\text{meas}}_{Sj,0} && \text{measured pressure minus settled value (psi)}\\ y &= (y_1, y_2, y_3)^{\mathsf T} = s - s_0 && \text{tip } (x, y, z) \text{ minus settled tip (mm)}\\ X &= (y,\ p) \in \mathbb R^6 && \text{state of M2}\\ r,\ e &= y - r && \text{reference, error (mm)}\\ \hat y,\ \tilde y,\ \tilde r && && \text{model output, predicted tip, previewed reference} \end{aligned} \]

Settled values: read once after 5 s at 4.5 psi, fixed for the run (5.48, 5.08, 5.53 psi).

Model (M2)

\[ \dot X = AX + B\,u(t - T),\quad y = CX,\qquad A = \begin{pmatrix} -\Lambda & \Lambda H\\ 0 & -\tfrac1\tau I\end{pmatrix},\ B = \begin{pmatrix} 0\\ \tfrac1\tau G\end{pmatrix},\ C = \begin{pmatrix} I & 0\end{pmatrix} \]

\(T = 0.50\) s dead time; \(\tau = 0.60\) s pressure lag; \(G = \operatorname{diag}(1.12, 1.10, 1.16)\) regulator gains; \(\Lambda = \operatorname{diag}(4.77, 4.70, 15.5)\) s⁻¹ settling rates; \(H\) (3×3, mm/psi) mixing. Derivation and identification: Model Discussion Guide §2–3.

Structure

Derivation

① Model without the delay

\[ \dot{\hat X} = A\hat X + B\,u(t),\qquad \hat y = C\hat X \]

Same \(A, B, C\) as M2, but driven by \(u(t)\), not \(u(t - T)\). So \(\hat y(t)\) is the model's estimate of \(y(t + T)\).

② Smith predictor

\[ \tilde y(t) = \underbrace{\hat y(t)}_{\text{model: } y(t+T)} + \underbrace{\big[\,y(t) - \hat y(t - T)\,\big]}_{\text{model error now}} \;\approx\; y(t + T) \]

\(\hat y(t - T)\) is the model's estimate of \(y(t)\) (stored for \(T\)), so the bracket is the model's current error, measured. Prediction = model forecast + current error. If the model were exact, \(\tilde y(t) = y(t + T)\). The bracket also carries every unmodelled effect (inertia, S1 leak, nonlinearity) back into the loop.

③ Reference preview

\[ \tilde r = r + T\dot r + \tfrac12 T^2 \ddot r \approx r(t + T),\qquad \dot{\tilde r} \approx \dot r + T\ddot r \]

\(\dot r, \ddot r\): backward differences of the received \(r\). The tip is predicted \(T\) ahead, so the target is too.

④ Sliding variable

\[ \sigma = \tilde y - \tilde r \]

Per axis. First-order mechanics, so \(\sigma = e\) form (paper eq. 4), on predicted quantities.

⑤ Control law

\[ \begin{aligned} &\text{mechanics (delay removed by ②):} && \dot{\tilde y} = -\Lambda\tilde y + \Lambda H p + d\\ &\text{require:} && \dot\sigma = \dot{\tilde y} - \dot{\tilde r} = -\lambda\sigma - \eta\operatorname{sat}(\sigma/\mu)\\ &\Rightarrow && p_{\text{des}} = H^{-1}\Lambda^{-1}\big[\dot{\tilde r} + \Lambda\tilde y - \lambda\sigma - \eta\operatorname{sat}(\sigma/\mu)\big] \end{aligned} \]

\(p_{\text{des}}\): pressure the arm needs. \(\lambda\): error decay rate. \(\eta\): switching gain. \(\mu\): boundary layer (mm). \(\operatorname{sat}\): \(\sigma/\mu\) inside \(|\sigma| \le \mu\), else \(\operatorname{sign}\sigma\).

⑥ Lag inverse

\[ \tau\dot p = -p + G u \ \Rightarrow\ u = G^{-1}\big(p_{\text{des}} + \tau\,\dot p_{\text{des}}\big),\qquad P^{\text{cmd}} = \operatorname{clip}(4.5 + u,\ 0,\ 9) \]

Solve the lag (step 7 of the derivation) for the command that makes \(p = p_{\text{des}}\). \(\dot p_{\text{des}}\): backward difference. The delay is already handled by ②.

⑦ Optional: disturbance observer (paper eqs. 6–8, 12, 14)

\[ \hat d = z + l_1\tilde y + l_2\tilde y|\tilde y|,\quad \dot z = g_o\big(\Lambda\tilde y - \Lambda H p - \hat d\big),\quad g_o = l_1 + 2l_2|\tilde y|;\qquad p_{\text{des}} \mathrel{-}= H^{-1}\Lambda^{-1}\hat d,\quad \eta = \Phi e^{-g_o t} + \epsilon/g_o \]

Estimates \(d\) and subtracts it. Measured effect below: negligible, because ② already feeds the model error back.

Reads and sends

Reads: \(y\) (motion capture), \(r\). Sends: \(P^{\text{cmd}}\) for S2, S3, S4 (3 values, 0–9 psi). Model identified beforehand from \(u\), \(p\) and \(y\) only.

Limits

  • \(T\) must be right: a wrong delay shifts the prediction (untested).
  • A disturbance faster than \(T\) is corrected only after \(T\).
  • Held-out task: commands at 0 or 9 psi in 21 % of samples.
  • Simulation only.
